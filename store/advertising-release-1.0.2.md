# 1.0.2 광고 출시 준비 — 아직 미제출

패키지 `com.softm.goldsignal`, versionName `1.0.2`, versionCode `3`.
현재 심사 중인 1.0.1을 취소하거나 대체 제출하지 않았다.

## Play 변경 필요사항

- 광고 포함: **예**. 기본 거부/선택형이어도 광고 SDK 포함 버전은 광고 있음으로 신고.
- 개인정보처리방침: `https://goldsignal.designboard.net/privacy.html` (광고 고지 개정본이 공개된 후 제출).
- 개발자 웹사이트: `https://goldsignal.designboard.net/`.
- 로그인/계정 생성: 없음. 모든 핵심 기능은 광고 거부 시에도 이용 가능.
- 타겟층: 기존 만 18세 이상 유지. 아동 대상 광고 설정을 임의로 변경하지 않는다.
- 광고 ID: `AD_ID` 및 AdServices 광고 관련 권한 제거. Android 구버전에서 권한 없이 식별자 접근이 가능한 경우까지 고려해 ‘광고 ID 미사용’을 단정하지 말고 최종 SDK 동작 및 Console 질문에 맞춰 검토.

## 데이터 보안 검토 초안

광고 SDK가 처리하므로 ‘데이터 수집/공유 없음’ 답변을 그대로 사용하지 않는다. 아래는 Google Mobile Ads 25.5.0 공식 데이터 공개에 따른 검토 범위이며 Console의 실제 항목과 최종 SDK 구성에 맞춰 확정한다.

| Play 항목 | 광고 SDK 처리 근거 | 제출 검토 |
| --- | --- | --- |
| 대략적 위치 | IP에서 대략적 위치를 추정할 수 있음 | 수집/공유, 광고·분석·부정 이용 방지 |
| 앱 활동 / 앱 상호작용 | 앱 시작·광고 탭 등 제품 상호작용 | 수집/공유, 동일 목적 |
| 앱 정보·성능 / 진단 | 성능·실행·응답 중단·에너지 정보 | 수집/공유, 동일 목적; 세부 하위 항목 확인 |
| 기기 또는 기타 ID | App Set ID 등 SDK 식별 정보 | 수집/공유. AD_ID 제거만으로 ‘ID 없음’이 되지 않음 |

- 전송 암호화: HTTPS/TLS.
- 목표가/시뮬레이터 입력: 로컬 전용, 광고 네트워크에 직접 전달하지 않음.
- 개인정보 이름/이메일/금융계좌/GPS/연락처/파일 권한 기능: 없음.
- 사용자 선택: 앱의 명시적 광고 허용 전 광고 요청·MobileAds 초기화를 하지 않음. UMP 자체 통신 및 SDK 시작 시 처리까지 확인한 뒤 ‘선택적 수집’ 여부를 확정한다.
- 데이터 삭제/보유: 운영자가 광고 사업자 데이터를 직접 삭제할 수 있다고 답하지 않는다. 실제 제공 기능·사업자 정책에 맞춰 검토한다.
- 공식 근거: https://developers.google.com/admob/android/privacy/play-data-disclosure
