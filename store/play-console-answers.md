# Google Play Console 제출 답변표

기준일: 2026-10-22 (한국시간). 앱 바이너리뿐 아니라 WebView에서 제공하는 운영 웹 화면이 바뀔 때도 아래 답변을 다시 검토한다. 현재 광고 포함 ‘예’ 저장은 확인했으나 검토 제출은 하지 않았다. 데이터 보안 3종은 임시저장했고 새로고침 후 유형별 완료 상태와 미리보기를 재확인했다. 최종 저장·검토 제출은 하지 않았다. 소스 수정·콘솔 저장·스토어 공개 반영을 구분한다.

## 금융 기능 선언

- 선택: 금융 조언
- 설명: 국제 금값·환율·국내 프리미엄을 사용한 일반 시장 정보와 시나리오 시뮬레이션을 제공한다.
- 제공하지 않는 기능: 개인 맞춤 투자 추천, 주문 실행, 자산 보관, 결제, 송금, 대출, 보험, 가상자산 거래
- 고지: 결과는 가능한 시나리오이며 실제 가격이나 투자 수익을 보장하지 않는다.

## 데이터 보안

| 질문 | 제출 준비 답변 |
|---|---|
| 사용자 데이터를 수집하거나 공유하는가 | **예**. 아래 3종을 수집 및 공유로 임시저장하고 재진입 확인 |
| 계정 생성·삭제 | 생성 없음, 계정 삭제 해당 없음 |
| 광고 SDK | **Kakao AdFit Web SDK 사용**. 네이티브 광고 SDK 추가와는 구분 |
| 분석 SDK | 별도 분석 SDK 추가 없음. AdFit 광고 측정 동작은 광고 SDK 검토에 포함 |
| 위치·연락처·사진 권한 | 요청 없음. 광고 제공자의 IP·식별자 처리까지 없다고 단정하지 않음 |
| 기기 또는 기타 식별자 | SDK 생성 `sdkid`·세션 `dk` 전송 코드 확인. 네이티브 GAID 수집과 구분 |
| 앱 상호작용 | 광고 표시·노출·클릭 이벤트의 외부 비콘 전송 경로 확인 |
| 진단 | 광고 SDK 요청·렌더·비콘 오류 보고 확인. 네이티브 앱 강제종료 로그와 구분 |
| 페이지·환경·서버 보유기간 | 상세 근거는 [데이터 보안 검토](data-safety.md). 유형별 서버 보유기간 미확정 |
| 목표 가격 | WebView 로컬 저장소 보관. 목표가를 서버로 전송하는 앱 기능 없음 |
| 쿠키 | Android WebView 쿠키·제3자 쿠키 차단 유지 |
| 전송 중 암호화 | 앱 자체 HTTPS 설정 확인. 광고 전체 전송 동작 확인 후 확정 |

기기 또는 기타 ID·앱 상호작용·진단의 공통 입력 기준은 **수집 및 공유 / 필수 / 임시 처리 아님 / 광고 또는 마케팅·애널리틱스**다. 임시저장 알림 및 새로고침 후 5단계 미리보기를 확인했다. 게시 개요로 보내는 최종 저장은 하지 않았다. 구체적 근거는 [데이터 보안 검토](data-safety.md)에 기록한다. SDK 생성 식별값을 네이티브 GAID 수집으로 해석하지 않는다.

**최종 제출 보류 사유:** 카카오 Web AdFit 서버의 IP 기반 위치 추론 여부가 확인되지 않았다. 따라서 대략적인 위치 유형의 필요 여부 및 위 3종이 전체 선언 범위인지는 확정할 수 없다. 이 내용을 확인하기 전 최종 검토 제출을 보류했다.

운영 웹은 [`ea7663d057545b5598e474159025a6439eb70c09`](https://github.com/softm/goldsignal/commit/ea7663d057545b5598e474159025a6439eb70c09), [배포 Actions 39635203459](https://github.com/softm/goldsignal/actions/runs/39635203459) 성공으로 반영되었으며 광고 동작 회귀 검사 9개가 통과했다. 이 상태는 Google Play의 선언 공개 반영 완료를 뜻하지 않는다.
